The Online Examination System is a console-based Python application designed to conduct multiple-choice examinations (MCQs).

The system allows students to answer questions, skip questions, and submit their responses. After the examination, the program automatically evaluates the answers and calculates the total score, percentage, correct answers, wrong answers, and skipped questions.

Finally, the system displays the examination result as PASS or FAIL based on the minimum passing percentage.
